# Jaydee Portfolio

Personal portfolio for **Opeyemi Adeparusi (Jaydee)**, a Frontend Developer.

The portfolio presents selected frontend projects, technical skills, development focus and contact information in a responsive React and TypeScript interface.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Router
- Radix UI
- Lucide React

## Featured Projects

- **Jobboard** — Vue 3, TypeScript, Pinia
- **Bookiosk** — JavaScript and API-focused frontend work
- **Paruxx** — business/product-focused frontend concept
- **Tunga** — JavaScript food-ordering interface

## Development Focus

- Responsive web interfaces
- Component-based React development
- Vue.js applications
- TypeScript
- Forms and user flows
- API-driven interfaces
- Accessible, maintainable UI

## Local Development

```bash
cd portfolio
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Run linting:

```bash
npm run lint
```
